# Hospital Management System SQL

## Project Overview
This project is a Hospital Management System developed using MySQL. It stores and manages hospital data using relational database tables and SQL queries.

## Technologies Used
- MySQL
- SQL

## Database Tables
- H_Department
- H_Doctor
- Nurse
- Patient
- H_Appointment
- Prescription
- Billing
- Payment

## SQL Concepts
- Database and table creation
- INSERT, UPDATE, and DELETE operations
- SELECT queries
- Primary keys and foreign keys
- Constraints
- JOIN operations
- Aggregate functions
- Subqueries

## Objective
To manage hospital information efficiently and retrieve useful data using SQL queries.
